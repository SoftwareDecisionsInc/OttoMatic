# OttoMatic

the GPAL browser recorder, by Software Decisions, Inc. Part of the GPAL family: https://gpal.sditx.com/

A browser extension for Chrome, Edge and Firefox that records what you do on a page as GPAL workflow code:
selectors with several paths each, match criteria and the actions between them. The tests folder holds the
pages used to exercise it, including nested iframes.

## This repository

This is the read-only public release mirror of OttoMatic version 1.0.0.1, taken from release commit `3ec2476` of
the private OttoMatic browser extension repository. Development happens privately, and pull requests are not accepted here.
